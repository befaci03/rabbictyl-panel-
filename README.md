# Rabbictyl Panel

Rabbictyl is a free, open-source game server management panel built with PHP, React, and Go. Designed with security
in mind, Rabbictyl runs all game servers in isolated Docker containers while exposing a beautiful and intuitive
UI to end users.

Stop settling for less. Make game servers a first class citizen on your platform.

### What's Supported?

Rabbictyl supports a very large variety of softwares (games, etc) by utilizing Docker containers to isolate each instance. This gives
you the power to run game servers without bloating machines with a host of additional dependencies.
